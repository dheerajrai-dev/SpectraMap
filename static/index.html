How SpectraMap Works

Geospatial Frequency Optimization & Graph Coloring Theory

1. The Radio Spectrum Scarcity Problem

Wireless network operators purchase expensive radio spectrum at national auctions. Radio frequency (RF) channels must be reused across geographic space because spectrum is strictly finite. However, if two nearby transmitters operate on the exact same frequency channel, their electromagnetic waves destructively collide — causing dropped calls, packet loss, and severe co-channel interference.

✖ Co-Channel Collision: Tower A (Channel f1) and Tower B (Channel f1) overlap → destructive radio interference.
✔ Proper Frequency Separation: Tower A (Channel f1) and Tower B (Channel f2) overlap → zero co-channel interference!
✔ Spatial Frequency Reuse: Tower A (f1) and Tower C (f1) are separated by > rA + rC → safe to reuse f1.

2. The Discrete Graph Theory Mapping

SpectraMap maps the physical geospatial layout directly into an undirected conflict graph G = (V, E):

Transceiver → Vertex (v ∈ V) Each cellular transmitter base station with coordinates (φi, λi) and estimated coverage radius ri.
Overlap → Edge ((u, v) ∈ E) An undirected conflict edge exists whenever geodesic distance d(u, v) ≤ ru + rv (coverage boundaries overlap).
Frequency Group → Color (c(v)) An assigned discrete frequency channel f1, f2, …, fk. Adjacent nodes must receive different colors.
Minimum Spectrum → Chromatic Number χ(G) The theoretical minimum number of non-interfering channels required to color graph G without any adjacent collisions.

3. Solver Mechanics & Theoretical Bounds

Determining the exact chromatic number χ(G) is an NP-hard problem. SpectraMap evaluates three complementary methods:

Welsh–Powell (1967) Static Greedy

Statically sorts vertices by descending graph degree Δ(v) and colors maximal independent sets in sequential passes. Extremely fast (O(V log V + E)), but can be trapped into using unnecessary extra colors because it ignores dynamic neighbor saturation.

DSatur (Brélaz, 1979) Dynamic Saturation

Dynamically tracks the saturation degree sat(v) — the number of distinct colors already assigned to neighbors. Always colors the most constrained uncolored vertex first, breaking ties with uncolored degree. Proven to achieve optimal or near-optimal colorings on cellular spatial topologies.

Exact DSatur Branch-and-Bound Exact Minimum (χ(G))

Pre-colors a maximum clique ω(G) at the root to break color permutation symmetry (eliminating k! redundant subtrees). Explores the state tree with DSatur vertex ordering and dynamic upper-bound pruning. Bounded to N ≤ 25 with a 500 ms monotonic deadline clock.

Theoretical Bounds Guarantees:
  • Clique Lower Bound: χ(G) ≥ ω(G). Because all vertices in a complete subgraph (clique) pairwise overlap, no two can share a frequency.
  • Brooks' Theorem Upper Bound: χ(G) ≤ Δ(G) + 1. For any connected graph that is neither a complete graph nor an odd cycle, χ(G) ≤ Δ(G).

4. Educational Model vs Real-World Cellular Engineering

While SpectraMap provides an accurate implementation of graph coloring theory, operational cellular networks (4G LTE, 5G NR) operate under continuous physical radio propagation constraints:

Dimension SpectraMap Discrete Model Real Cellular Network (4G/5G)
Coverage Geometry 2D circular disks with radius ri. 3-sector directional antennas (120° azimuths) with electrical downtilt and irregular RF shadow fading.
Interference Boundary Binary collision (overlap = edge; no overlap = no edge). Continuous Signal-to-Interference-plus-Noise Ratio (SINR) and path loss models (Hata, COST-231, 3GPP 38.901).
Frequency Allocation Discrete hard channel groups (f1, f2, …). OFDMA subcarrier resource blocks, dynamic Fractional Frequency Reuse (FFR), and carrier aggregation.
Power & Optimization Static coverage radius. Dynamic closed-loop transmit power control (TPC) and Coordinated Multi-Point (CoMP) beamforming.
