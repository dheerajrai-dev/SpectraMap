# SpectraMap

**Spatial Graph Coloring for Cellular Frequency Optimization**

SpectraMap is an academic project that applies discrete mathematics and graph-coloring algorithms to cellular frequency allocation.

## Objectives

- Build an interference graph from cell-tower data.
- Implement and compare DSatur and Welsh–Powell.
- Verify frequency assignments for conflicts.
- Visualize towers and their assigned frequencies on an interactive map.

## Planned Technology Stack

- Python, NetworkX and FastAPI
- Pandas, GeoPandas and Shapely
- React, TypeScript and Vite
- React Leaflet and OpenStreetMap
